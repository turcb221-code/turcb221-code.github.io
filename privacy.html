Privacy Policy

Sovana Backup

Purpose

Sovana Backup is a private utility used by its owner to create and store backup copies in Google Drive.

Google Drive access

The application may request access to Google Drive only for creating, uploading, reading, and managing backup files required for its backup function.

Data handling

Backup data remains under the control of the application owner. This website does not host application databases, backup archives, credentials, OAuth tokens, customer records, or other operational data.

Data sharing

Sovana Backup does not sell personal data and does not provide backup data to third parties except where necessary to use Google Drive as the storage provider selected by the application owner.

Retention

Backup retention is controlled by the application owner and may be configured or deleted at any time.

Security

Authentication credentials and OAuth tokens are not published on this website and should be stored only in the secured application environment.
